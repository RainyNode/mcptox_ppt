# MCPTox 论文汇报与复现实验归档

本项目围绕论文 **MCPTox: A Benchmark for Tool Poisoning Attack on Real-World MCP Servers** 展开，用于整理论文阅读、组会汇报、攻击流程图制作以及复现实验材料。

> 本仓库不是 MCPTox 官方源码仓库，而是基于论文内容制作的汇报与研究归档，包含个人整理的图表、演示文稿、复现实验结果和辅助材料。

## 项目简介

MCPTox 研究真实 MCP（Model Context Protocol）服务器中的工具投毒攻击：攻击者通过篡改工具描述，将恶意指令伪装成正常的工具说明，诱导 LLM Agent 调用工具执行非预期操作。

本项目的工作重点是把论文中的威胁模型、攻击范式、数据集构建流程和实验结论整理成适合汇报和讨论的材料，并对论文中的实验进行小规模复现和扩展验证。

## 已完成的工作

### 1. 论文内容梳理

- 整理 MCPTox 的研究背景、问题定义和安全挑战。
- 梳理 MCP 工具描述带来的新信任边界，以及它与传统 Prompt Injection 的区别。
- 总结三类工具投毒攻击范式：
  - P1：显式触发的功能劫持；
  - P2：隐式触发的功能劫持；
  - P3：隐式触发的参数篡改。
- 整理论文中的数据集构建流程、评估指标、主实验结果、失败模式和防御机制分析。

### 2. 汇报材料制作

- 制作 MCPTox 论文汇报 PPT，并统一调整为适合组会展示的结构和视觉风格。
- 制作 MCP-Persona 相关论文汇报材料，用于补充 MCP Agent 和个性化工具场景的背景对比。
- 将论文中的攻击链路、MCP 交互流程、攻击面和评估流程转化为可编辑的 Visio 图。
- 制作研究背景、攻击范式、样本生成和防御插入点等 HTML 草稿，用于图表设计和内容迭代。

### 3. 复现实验与扩展验证

- 基于 MCPTox 的评估思路开展 50 条样本、3 个模型的小规模复现。
- 开展 300 条样本、2 个模型的扩展实验。
- 统计 ASR（Attack Success Rate）和 Refusal Rate 等指标。
- 对 P1/P2/P3 不同攻击范式、Credential Leakage、Service Disruption 等高风险类别进行观察。
- 记录模型差异、样本规模变化、无效响应处理方式以及目标模型兼任 Judge 可能带来的自评偏差。

复现实验用于验证论文结论和支持研究讨论，属于探索性证据，不应直接解释为与论文主实验完全可比的结果。

### 4. 工具与质量检查

- 使用 PowerShell 脚本生成和维护 Visio 图。
- 使用文本重叠检查脚本检查 Visio 图中的文字形状是否发生重叠。
- 保留论文原文、中文翻译、研究疑点记录和设计文档，方便后续核对和修改。

## 使用说明

1. 汇报时优先使用 `01_最终交付/` 下的 PPT。
2. 需要修改流程图时，打开 `02_Visio源文件/` 下的 `.vsdx` 文件进行编辑。
3. 需要重新生成或检查 Visio 图时，使用 `03_脚本工具/` 下的 PowerShell 脚本，并根据脚本中的路径配置进行调整。
4. 论文原文和中文翻译位于 `06_参考论文/`，用于核对论文中的定义、数据和实验结论。

## 当前限制

- 复现实验的样本量和模型集合与论文主实验不同，不能据此进行严格的跨实验排名。
- 部分复现实验使用目标模型兼任 Judge，可能存在自评偏差。
- 复现实验结果主要用于验证趋势、发现失败案例和支持汇报讨论，不代表 MCPTox 官方实验结果。
- 仓库中的 PDF 参考论文仅作为本地研究材料，按仓库规则不纳入 Git 版本提交。
