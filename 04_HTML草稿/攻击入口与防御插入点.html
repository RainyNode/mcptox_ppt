Tool Poisoning攻击链
Untrusted MCP Server
不可信第三方工具源
↓
Tool Registration
工具注册 / 元数据加载
↓
Poisoned Tool Description
恶意指令嵌入 Tool Metadata
↓
LLM Context / Planning
模型将描述纳入上下文并参与决策
↓
Tool Selection & Parameters
选择合法工具或篡改调用参数
↓
Legitimate Tool Execution
通过合法工具完成恶意操作
↓
Malicious Outcome
隐蔽越权 / 数据泄露 / 参数篡改
Attack Surface
Metadata Sanitization
• 扫描工具描述中的可疑指令
• 过滤恶意 imperative language
• 降低注册阶段注入风险
Tool Call Validation
• 检查调用是否符合用户意图
• 检测参数恶意修改
• 拦截异常 Tool Call
Sandbox / Runtime Monitoring
• 隔离不可信 MCP Server
• 高风险调用运行时审计
• 限制权限逃逸
Tool Poisoning 的核心风险在于：恶意指令在工具注册阶段进入 LLM Context，而非传统用户输入阶段。
